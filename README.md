## あらすじ / 設定
主人公「なお」（大人）は、NCT WISH日本公演の通訳兼アーティストサポートスタッフとして帯同する。舞台は2027年2月下旬〜3月7日、東京・国立代々木競技場第一体育館（2/26〜28）→兵庫・GLION ARENA KOBE（3/5〜7）。

**規模感の前提（史実準拠）**：NCT WISHは2027年時点で既に人気が確立したグループ。2024年2月に東京ドームでデビューショーケースを行い、2026年は『WISHLIST』（1/14）、『Ode to Love』（4/20・Circle累計約187万枚）、『YO-I-DON!/BOY MEETS GIRL』（7/15・RIAJ 2×プラチナ）、『I SPY』（10/12・Hanteo初日約120万枚、4作連続ミリオンセラー）、音楽番組1位通算12冠。2ndツアーは2027年1月にソウル・高尺スカイドームで開幕し、日本公演のチケットは完売前提。スタッフの緊張は「集客」ではなく「満員の期待に応える公演を無事故で完璧に回すこと」に置かれる。なお神戸はツアー千秋楽ではなく、公演は福岡・北九州メッセ（3/13〜14）、愛知・ポートメッセなごや（3/21〜22）へ続く（エピローグで明示）。

## システム
- ゲージ3種：公演完成度／コンディション／信頼度。選択肢とミッション（通訳フォロー・楽屋ケア・SNS撮影補助・トラブル対応・休憩確保から2つ選択）で変動し、後段のセリフとエンディングに反映。
- エンディング3種：パーフェクトツアーEND／あたたかい完走END／ほろ苦い完走END。達成条件はゲージ複合（例：パーフェクトは完成度80・コンディション70・信頼度76以上）。到達ENDはlocalStorageにコレクション保存。
- クリア後：サクヤとのフリーチャット解放（キーワード応答18種＋デフォルト応答）。
- セーブはlocalStorage自動保存。ボイスは未収録（通話は独立シーン構造で後付け可能）。
